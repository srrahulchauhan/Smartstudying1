# StudyFlow – Smart Study Tracker

A modern, comprehensive Study Management and Productivity Tracker built with React, Tailwind CSS, and LocalStorage.

## 🚀 Features

- **Dynamic Interactive Dashboard**: 8 interactive stat cards with live progress animations, ticking live counters, audio-visualizer soundwave bars, and direct page routing.
- **Multiple Preparations & Plans**: Create and switch between distinct study goals (MERN Stack, Govt Exam, UPSC, GATE, etc.) with isolated subjects, syllabus topics, and schedules.
- **Comprehensive Subject & Topic Hierarchies**: Track topics by status (Not Started, In Progress, Completed), confidence level (High, Medium, Low), and target completion dates.
- **Timestamp-Accurate Study & Break Timer**: Accurate timer without drift, break tracking excluded from study time, pause/resume, and reload recovery via LocalStorage.
- **Auto & Manual Attendance Engine**: Automatic attendance calculation based on minimum study thresholds (default 30 mins) with Present/Absent/Partial tracking.
- **Timetable & Schedule Planner**: Daily and weekly schedule with recurring slots, study reminders, and status indicators.
- **Target Tracking**: Daily, Tomorrow, Weekly, and Monthly target progress bars with real-time accumulation.
- **Interactive Calendar**: Monthly calendar grid with color-coded daily study hours and attendance badges.
- **Detailed Study History**: Audit log of all completed sessions with subject/topic filters and date range search.
- **Visual Analytics**: Interactive 7-day study breakdown, subject distribution charts, and productivity metrics.
- **Focus Mode & Pomodoro**: Distraction-free full-screen environment with ambient background sounds, Pomodoro intervals, and motivational quotes.
- **Goals with Milestones**: Target deadlines, progress bars, and celebration confetti on completion.
- **10-Sheet Excel Export**: Full backup and comprehensive `.xlsx` export across all preparations, subjects, sessions, attendance, and timetable using SheetJS.
- **Theme & Customization**: Sleek dark and light modes, customizable attendance rules, and notification sound alerts.

## 🛠️ Tech Stack

- **React.js** (JavaScript only, no TypeScript)
- **Tailwind CSS v3** (Glassmorphism & animations)
- **Lucide React** (Icons)
- **SheetJS (xlsx)** (Multi-sheet Excel export)
- **Canvas-Confetti** (Goal completion celebrations)
- **Vite** (Fast modern build tool)
- **LocalStorage API** (Persistent client-side database)

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/srrahulchauhan/Studytracker3.git
cd Studytracker3
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
